# InvoiceApp - AI-Readable Information

## Application Overview
InvoiceApp is a professional invoice and proposal management system designed for contractors, construction businesses, and service providers.

## Primary Functions
1. Invoice Management
   - Create, edit, and manage invoices
   - Track payment status
   - Support for multiple order types (Day Work, Contract, Extra)
   - Multi-currency support
   
2. Proposal Management
   - Create detailed proposals
   - Convert proposals to invoices
   - Include work descriptions and payment terms
   - Digital signature collection
   
3. Client Management
   - Store client information
   - Track billing history
   - Manage contact details
   - Monitor payment status
   
4. Job Tracking
   - Work log tracking
   - Photo documentation
   - Receipt management
   - Progress monitoring

## Key Features
- Digital signatures for invoices
- PDF generation and export
- Multi-language support (English/Spanish)
- Mobile-responsive design
- iPad-optimized PDF generation
- Dark mode support
- Payment tracking
- Financial reporting
- Company branding customization
- Secure authentication

## Technology Stack
- Frontend: Next.js 14, React, TypeScript, Tailwind CSS
- Backend: Node.js, Express
- Database: PostgreSQL with Prisma ORM
- Storage: Supabase
- PDF: html2canvas, jsPDF
- Authentication: JWT
